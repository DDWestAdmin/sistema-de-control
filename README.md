como conectar repositorio en android studio
Abre Android Studio y en la pantalla de inicio selecciona Get from VCS (o ve al menú File > New > Project from Version Control).
En el menú desplegable de "Version control", asegúrate de que esté seleccionado Git.
Pega la URL del repositorio ([(https://github.com/DDWestAdmin/sistema-de-control.git)]) en el campo "URL".
Elige la carpeta donde quieres guardarlo en "Directory" y haz clic en Clone.
